MiniBrowser C11 Rendering Engine

A self-contained modular web browser engine built with C11, SDL2, and SDL2_ttf.

Features & Architecture Verification

This engine implements a full HTML5 tokenizer, hierarchical DOM tree, CSS cascade parser, box-model layout, persistent cookie jar, and SDL2 painting.

Try the interactive capabilities below:

Trigger Modal Dialog Open New Window (target=_blank) Script Window (window.open) Navigate Current Window

CSS Box Model & Specificity

The layout engine computes vertical block flow and horizontal inline text wrapping.

Box Model: Content, padding, borders, and margins are calculated with top-down width propagation and bottom-up height resolution.

Inline tags work as expected: HTML5 DOM CSS Cascade Shared Cookies POSIX Sockets

State & Shared Cookie Jar

The global CookieJar instance is shared between all spawned windows. Cookies support Max-Age, Path, Domain, and HttpOnly attributes.

Clicking an auxiliary link creates an independent SDL2 window that accesses the exact same cookie storage.
